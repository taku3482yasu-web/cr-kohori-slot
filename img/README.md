# img/ — 差しかえの画像

## okagappa-ikemen.png（おかランプの一発告知のおかがっぱ・なくてもよい）

おかランプ（オカピポ）で 1 ゲームの上乗せが 300 枚以上（`config.tokka.ikemen.minAdd`）に決まると、
イケメン風のおかがっぱの一発告知が流れる（`js/lcd/ikemen-view.js`）。

- このファイルが **ない** とき：ドット絵のおかがっぱ（流し目・きりっとしたまゆ・バラをくわえた顔のアップ）
- このファイルを **置いた** とき：ドット絵のかわりに、この画像を液晶の右側に出す（高さを液晶に合わせる）

画像のめやす：
- PNG（背景が透明だと、虹色の背景の上にきれいに乗る）
- 縦長〜正方形。液晶は 256×144 の 2 倍で表示なので、高さ 300〜600 px くらい
- 左側は「おかがっぱ」「おかピポ…イェア。」「+N枚!!」の文字が乗るので、顔は右に寄せる
