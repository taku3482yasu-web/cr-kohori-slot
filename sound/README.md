# sound/ — 曲のファイル

ほかの曲（通常時・SE城前・RASH・SUPER・敗北・ダンス・ほかの特化ゾーン）も、`sound/<名前>.mp3` を置けば差しかわる。Suno に入れる内容は **`sound/SUNO.md`**。
音の試聴は `tools/sound-test.html`。

## okapipo.mp3（上乗せ特化ゾーン「おかランプ」の曲）

ここに `okapipo.mp3` を置くと、おかランプ（オカピポ）の間にこの曲が流れる（`js/bgm.js` の `BGM_FILES`）。
置いていないとき・読めないときは、今までのチップチューンのダンスの曲が流れる。

- ファイル名は **`okapipo.mp3`**（ほかの名前・形式にするなら `js/bgm.js` の `BGM_FILES.okapipo.src` を変える）
- 曲はくり返し流れる（ループ）。終わりと始まりがつながりやすい曲だと気持ちいい
- 音量は `BGM_FILES.okapipo.gain`（0.85）で、チップチューンとの大きさをそろえる。⚙ SETTINGS の BGM 音量・オンオフも効く
- 曲は少しずつ読み込むので、ホーム画面に追加したアプリでネットにつながっていないときは、チップチューンになる

### 置き方

1. Suno で何曲か作って、いちばん盛り上がるものを選ぶ
2. MP3 でダウンロードして、名前を `okapipo.mp3` にする
3. このフォルダ（`sound/`）に入れる
4. `index.html` を開き、デバッグパネルの「特化:おかランプ」で確かめる

※ Suno の無料プランで作った曲は、商用に使えない決まり（作った人の個人の遊び・非商用の公開ならだいじょうぶ）。お金をとって配るなら有料プランで作る。
